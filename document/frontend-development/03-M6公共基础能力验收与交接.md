## 5. 新业务页面接入规范

### 5.1 目录和命名

- 页面放在`src/views/<domain>/`，Vue组件使用PascalCase，例如`CourseListView.vue`。
- 领域模型放在`src/types/`，页面不得直接消费暂定DTO。
- 页面调用的接口定义放在`src/services/`；Mock与HTTP分别放在`src/mocks/`和`src/services/http/`。
- DTO与映射函数放在`src/api/transport.ts`和`src/api/mappers/`。
- 稳定通用交互优先复用`src/components/common/`，业务摘要组件放在`src/components/business/`。

### 5.2 路由、菜单和权限

每个业务路由至少声明：

```ts
meta: {
  title: '课程中心',
  requiresAuth: true,
  roles: ['EMPLOYEE', 'MANAGER', 'HR', 'ADMIN'],
  menuKey: 'courses',
  breadcrumb: ['培训中心', '课程中心'],
  keepAlive: false,
  priority: 'P0',
}
```

- 菜单配置集中在`src/config/navigation.ts`。
- 角色与操作权限集中在`src/config/permissions.ts`，页面不得散落角色字符串判断。
- 菜单隐藏、路由守卫和按钮禁用共同改善体验，但不能替代后端鉴权。
- 详情路由只传资源ID，刷新后必须重新查询，不得依赖上一页传递完整对象。

### 5.3 服务与错误处理

页面只调用领域服务：

```ts
const service = await getCourseService()

try {
  const result = await service.listCourses(query, { signal })
  rows.value = result.items
} catch (error) {
  if (isServiceError(error)) uiError.value = error.ui
}
```

- `UiError.fieldErrors`映射到对应表单字段。
- `traceId`只用于问题定位，不向用户展示内部堆栈或SQL信息。
- 查询请求仅对可恢复故障最多重试一次。
- 写操作不自动重试；超时或断线显示“结果未知”，引导查询最新状态。
- 连续查询使用`LatestRequestController`取消旧请求；写操作使用`SingleFlightController`避免重复提交。
- 真实认证头和最终响应包裹结构未冻结，只能在HTTP适配层替换。

### 5.4 列表状态恢复

- 搜索词、筛选条件、`page`和`pageSize`写入路由`query`，条件变化时页码回到1。
- 使用`readQueryString`、`readPositiveQueryInteger`和`compactListQuery`解析及生成查询参数。
- 进入详情时保留列表URL；返回优先使用浏览器历史，直接打开详情时回退到列表默认路由。
- Router已优先恢复浏览器`savePosition`；新列表不得在挂载后无条件滚动到顶部。
- 返回列表后重新查询可能变化的行，不缓存服务端业务结论。

### 5.5 公共组件选择

| 场景 | 组件 |
| --- | --- |
| 页面标题、面包屑、主操作 | `PageHeader` |
| 查询条件 | `SearchPanel`、`FormField`、`AppSelect` |
| 列表与分页 | `DataTable`、`AppPagination` |
| 加载、空、无结果、失败 | `PageState` |
| 状态文字 | `StatusTag` |
| 危险或不可逆操作 | `ConfirmDialog` |
| 详情字段和流程 | `AppDescriptions`、`ProcessTimeline` |

公共组件完整状态入口为`/components`。不要为了单个页面复制公共组件样式，也不要过度封装Element Plus的临时业务差异。

## 6. 枚举和未知值

- 传输枚举使用后端英文值，领域层映射为安全的中文展示值。
- 未识别值统一映射为`UNKNOWN`或“未知状态”，不得映射成其他合法业务状态。
- 未知状态默认禁止危险操作，并在开发/联调日志中记录原始值和`traceId`。
- 名额、资格、预算、实际学时和证书有效性只展示服务端结果，不在页面拼装业务结论。

## 7. 环境切换

| 模式 | 配置文件 | 启动命令 | 规则 |
| --- | --- | --- | --- |
| Mock | `.env.mock` | `pnpm dev` | `VITE_USE_MOCK=true`，不要求Base URL |
| 本地后端 | `.env.local`（由示例复制） | `pnpm dev:local` | `VITE_USE_MOCK=false`，Base URL必填 |
| 联调 | `.env.integration.local`（由示例复制） | `pnpm dev:integration` | `VITE_USE_MOCK=false`，Base URL必填 |

配置由`src/config/env.ts`统一解析。页面、Store和组件不得读取`VITE_API_BASE_URL`或拼接接口地址；真实密钥、账号、Cookie和Token不得提交仓库。
