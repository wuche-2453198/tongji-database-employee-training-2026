# 页面接口映射与联调阻塞

## 1. 状态定义

- **已接入**：当前仓库存在对应后端 Controller/DTO，前端已按源码实现适配；仍需真实环境账号完成运行验收。
- **已适配、待后端**：前端按业务分支记录实现路径和字段，但当前整合基线没有对应后端 Controller/OpenAPI，不能宣称联调完成。
- **Mock验收**：页面、领域服务、Mock仓储和自动化已完成；真实 HTTP 契约缺失时明确阻塞。

## 3. 当前后端已确认契约

认证证据来自：

- `src/backend/TrainingManagement.Api/Controllers/AuthController.cs`
- `src/backend/TrainingManagement.Api/Dtos/Auth/LoginRequest.cs`
- `src/backend/TrainingManagement.Api/Dtos/Auth/LoginResponse.cs`
- `src/backend/TrainingManagement.Api/Dtos/Auth/AuthUserResponse.cs`
- `src/backend/TrainingManagement.Api/Common/Security/RoleCodes.cs`
- `src/backend/TrainingManagement.Api/Common/Security/PermissionCodes.cs`

确认结果：

- 登录字段是`Identifier`与`Password`，JSON适配为`identifier/password`。
- 登录返回`AccessToken`、`TokenType=Bearer`、`ExpiresAt`与当前用户。
- 当前用户包含`EmpId`、`EmpName`、部门、岗位、状态、角色集合和权限集合。
- 角色码为`ADMIN`、`HR`、`DEPT_MANAGER`、`EMPLOYEE`。
- 权限码为点号格式，例如`course.read`、`request.create`、`request.approve`、`request.file`。

## 4. 联调问题清单

| 编号 | 优先级 | 问题 | 影响 | 当前处理 |
| --- | --- | --- | --- | --- |
| INT-FE-001 | P0 | 当前整合基线没有课程Controller/OpenAPI | 课程真实模式无法运行验收 | 保留HTTP适配与Mock，等待课程模块合入 |
| INT-FE-002 | P0 | 当前整合基线没有培训申请Controller/OpenAPI | 申请、审批、备案无法真实联调 | 按业务分支记录适配，等待模块合入并契约测试 |
| INT-FE-003 | P0 | 报名、签到、证书后端模块未合入 | 后半段主链路只能Mock验收 | HTTP能力显式阻塞，不宣称成功 |
| INT-FE-004 | P1 | 课程操作资格没有冻结接口 | 真实详情页不能安全启用申请/报名按钮 | 缺失时默认禁止，由写接口最终校验 |
| INT-FE-005 | P1 | 培训申请分页、关键词、日期筛选字段未冻结 | UI筛选与服务端能力可能不一致 | 只发送已记录的Status/Page/PageSize |
| INT-FE-006 | P1 | HR备案意见字段在页面存在、后端记录称不支持 | 真实模式不能持久化备案意见 | 当前不发送并在本表明确记录 |
| INT-FE-007 | P1 | 后端没有退出/Token撤销接口 | JWT在服务端到期前无法主动撤销 | 前端清本地Token；等待后端决策 |
| INT-FE-008 | P1 | 本机没有.NET SDK | 无法在本次整合环境执行后端build/test | 未改后端认证源码；记录为验证环境阻塞 |

## 5. 联调验收门禁

1. 对应后端模块合入并提供可追踪Swagger/OpenAPI。
2. 使用四角色真实账号验证200、401、403、404、409和500。
3. 验证后端数据范围：员工本人、主管本部门、HR授权范围。
4. 验证分页、空值、日期、枚举、字段错误和`traceId`。
5. 验证写操作并发、幂等或结果未知后的查询协议。
6. 只有真实环境测试通过后，才能把“已适配、待后端”更新为“联调通过”。
