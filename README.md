# 企业内部培训管理系统

同济大学数据库课程设计项目，采用前后端分离架构。

## 前端

前端工程位于 `src/frontend/training-management-web/`，使用 Vue 3、TypeScript、Vite、Vue Router、Pinia 和 Element Plus。

```sh
cd src/frontend/training-management-web
pnpm install --frozen-lockfile
pnpm dev
```

完整的环境要求和检查命令见 [`src/frontend/README.md`](src/frontend/README.md)。
