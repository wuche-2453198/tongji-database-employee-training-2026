# 前端入口

维护协调人：李司翰；业务页面负责人：彭浩。

交付内容：Vue 3 + TypeScript + Vite 工程、登录页、路由守卫、用户 Store、Axios API 客户端、主布局、权限菜单、403/404 页面、公共表格和表单规范。工程代码位于 `frontend-integration` 分支，合入 `develop` 前本目录只有本说明。

前端只调用 HTTP API，不直接访问 Oracle。业务页面必须使用公共 API 客户端、类型和状态枚举映射。开发期可参考项目分工中的建议接口或当前 Swagger；进入联调后必须与后端当前实现保持一致，模块最终验收前补齐页面映射和接口文档。详细规范见 [技术架构与开发规范](../../document/02-技术设计/技术架构与开发规范.md)。
