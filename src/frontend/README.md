# 前端工程

前端应用位于 [`training-management-web/`](./training-management-web/)。

- 技术栈：Vue 3、TypeScript、Vite、Vue Router、Pinia、Element Plus。
- 包管理器：pnpm，仓库只提交 `pnpm-lock.yaml`。
- 默认数据模式：Mock；真实认证和业务接口等待后端契约冻结后接入。
- 启动与检查：参见应用目录 [`README.md`](./training-management-web/README.md)。
- 技术决策：参见 [`M0 技术决策记录`](../../document/frontend-development/02-M0技术决策记录.md)。
